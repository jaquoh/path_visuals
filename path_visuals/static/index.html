Supported data structures

Paste files into the project's data/ folder and choose Refresh. Choose a file, then toggle its objects independently.

CSV / TSV — recommended

UTF-8 with a header. Comma, semicolon and tab delimiters are detected automatically. Use a dot for decimals. 

object_id,timestamp,latitude,longitude
bike-01,2026-09-08T08:00:00Z,52.516,13.378
bike-01,2026-09-08T08:01:00Z,52.517,13.379

Required: timestamp, latitude, longitude.
Optional: object_id (defaults to filename), segment (path breaks), level (floor; blank means unknown).

Aliases: user → object_id, time → timestamp, lat → latitude, lon / lng → longitude.

GPX 1.0 / 1.1

Tracks with timestamped trkpt points. Each track is an object; track segments stay separate. Routes and untimed waypoints must first be converted to CSV.

Time & coordinates

ISO 8601 timestamps; offsets are normalized to UTC. Timestamps without an offset are interpreted as UTC. Coordinates must be WGS84 decimal degrees. Observations are sorted by time. Invalid rows produce an error rather than being silently dropped.

Limits: 25 MiB and 100,000 observations per file. Convert other sources, including GeoJSON, to the CSV structure above. Density shows observation concentration, not time-weighted dwell.
