# Movement data

Paste CSV, TSV or GPX files directly here, then press Refresh in the app.
See the supported data structures section in the root README or the in-app guide.

The three demo files are fictional and reproducible with `uv run python scripts/generate_demo.py`.
`demo-city.csv`: three city routes; `demo-campus.csv`: four robots on two floors using
semicolon-separated data; `demo-walk.gpx`: one timestamped walking track.
Only demo files and this README are included in Git. Other data remains local.
